# TC-10a — Encounter Builder composition

Execute only this slice. Build the core Encounter Builder composition UI from the approved design.

Suggested structure: library/search region + encounter composition + summary/context region. Allow fast monster search/add, quantity adjustments, removal, Character/participant addition, and initial-state setup. Drag-and-drop may be supported but must never be required.

Use the shared context panel for monster inspection without leaving the builder.

Acceptance: a DM can construct a realistic encounter quickly with mouse/keyboard and on tablet.
