# TC-08a — Monster Library

Execute only this slice. Implement the fast DM Monster Library from the approved design.

Use realistic D&D fixture data behind generic repository interfaces. Support search and progressive filters such as name, CR/difficulty, type, size, source, and environment when available.

Rows/cards must be information-dense and easy to scan; do not make it an ecommerce grid. Primary actions include open details, add to encounter, clone, and create custom monster.

Include loading, empty custom-content, no search results, and long-list states.

Acceptance: search/filter interactions are usable on desktop/tablet, design fidelity is high, and opening a monster can use the reusable context-panel architecture.
