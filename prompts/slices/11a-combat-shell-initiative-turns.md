# TC-11a — Live Combat shell, initiative, rounds, turns

Execute only this slice. This is the highest-priority Phase 1 screen. Implement the DM Live Combat desktop/tablet command center from the approved design.

Must handle at least 4 Players + 8 Monsters + 1 NPC without giant cards. Show current round, unmistakable current turn, initiative order, participant identity/type, HP, AC, conditions, and fast access to details.

Implement initiative roll/set/reorder, next/previous/advance turn logic as supported, round progression, and a reusable context panel.

The active participant must be clear without relying only on color.

Acceptance: a DM can run turn order efficiently at desktop and tablet widths without leaving the combat workspace.
