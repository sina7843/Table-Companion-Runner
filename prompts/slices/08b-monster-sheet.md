# TC-08b — Monster Sheet

Execute only this slice after TC-08a. Implement the Monster Sheet/detail experience.

Prioritize name, CR/difficulty, AC, HP, speed, core stats, saves, resistances, immunities, senses, traits, actions, reactions, legendary actions, and spells where relevant. Actions must expose direct roll affordances using shared roll primitives.

Support full-page detail plus contextual panel/drawer when opened from Encounter or Combat. Do not copy printed-paper stat-block styling; implement the approved modern design.

Acceptance: long actions, many traits, many spells, and contextual opening remain readable and performant.
