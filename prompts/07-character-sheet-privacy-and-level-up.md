# TC-07 — Character Sheet Privacy And Level Up

```text
Execute TC-07. Implement Character Sheet, Character editing, Party privacy controls, and guided Level Up.

Prioritize play-critical info: HP, AC, initiative, conditions, attacks/actions, spells, saves, key abilities. Long-form content is secondary.

Implement sections consistent with the approved design: overview, abilities, skills/saves, combat, spells, inventory, features, background, privacy/settings as applicable.

Privacy states: owner full access; DM full access; other Players only public sections. Make privacy understandable beyond a tiny lock icon.

Level Up must reuse builder patterns and clearly show automatic changes vs required choices.

Acceptance: mobile Player sheet is fast to use during play; desktop/detail variants work; privacy and level-up states are testable with fixtures.
```
