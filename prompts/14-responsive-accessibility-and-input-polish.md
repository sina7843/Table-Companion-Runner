# TC-14 — Responsive Accessibility And Input Polish

```text
Execute TC-14. Perform a dedicated responsive, accessibility, keyboard, pointer, and touch pass across all completed Phase 1 surfaces.

Test DM desktop, DM tablet, Player mobile, long names, 20+ spells, 12+ combatants, multiple conditions, low HP, long monster actions, empty states, and narrow widths.

Fix WCAG-conscious contrast, focus visibility, semantic labels, non-color-only status communication, touch target sizing, reduced motion where appropriate, and focus trapping/return for overlays.

Acceptance: no major flow relies on hover-only interaction or color alone; tablet combat remains operational; mobile actions are comfortably tappable.
```
