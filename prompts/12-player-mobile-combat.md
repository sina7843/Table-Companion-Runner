# TC-12 — Player Mobile Combat

```text
Execute TC-12. Implement the Player mobile Active Combat experience from the approved design.

Must show current round, whose turn, clear own-turn emphasis, HP/key state, conditions, available actions, recent roll/result, target state, and End Turn.

Actions should open the smallest useful interaction surface, not nested modal chains. Reuse Character actions/spells and shared roll/HP/condition components.

Include Player-turn, waiting-for-turn, low-HP, unconscious/death-save (D&D ruleset), reconnecting, and combat-ended states.

Acceptance: a Player can understand and execute a turn within seconds on a phone.
```
