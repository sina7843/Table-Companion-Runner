# TC-08c — Custom / Clone Monster

Execute only this slice after TC-08b. Implement create-from-scratch, clone-existing, and edit-cloned Monster flows.

Avoid one giant form. Group fields logically, use progressive disclosure, validate ruleset-aware fields where possible, and provide a live/near-live sheet preview.

Phase 1 homebrew scope is Monster only. Do not add custom class/subclass/species/background/spell/item/feat editors.

Acceptance: a DM can clone a standard monster, change combat stats/actions, preview it, save it, and then find/use it in Monster Library and Encounter Builder.
