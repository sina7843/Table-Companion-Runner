# Table Companion prompt runner quick start

Run `04-COPY-NEXT-PROMPT.cmd` with no argument to copy the first unchecked `TC-*` item from `PROJECT_STATUS.md`.

Manual examples:

```bat
04-COPY-NEXT-PROMPT.cmd 03
04-COPY-NEXT-PROMPT.cmd 10a
```

Large parents `08`, `10`, and `11` are intentionally sliced; run a, then b, then c.
